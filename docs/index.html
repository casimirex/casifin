NASA-grade safety by default

Every line of library code follows rules adapted from the NASA/JPL Power of Ten. We check arithmetic, bound loops, and propagate every error explicitly.

🛡️

Defensive arithmetic

All business-logic functions use rust_decimal checked_add, checked_sub, checked_mul, checked_div, checked_powi, checked_powd, and checked_ln. Overflow and division-by-zero map to typed CasifinError variants and are propagated with ?.

Quick-start tutorials

Copy, paste, and run. Every snippet uses the casifin_sdk entry point so you only import one crate.

1. Add casifin to your project

Put this in your Cargo.toml and import the SDK.

toml[dependencies]
casifin_sdk = { path = "crates/casifin-sdk" }
rust_decimal = "1.35"

2. Your first calculation

Create the engine, build a rate, and compute the future value of a lump sum.

rustuse casifin_sdk::*;
use rust_decimal::Decimal;

fn main() -> Result<(), CasifinError> {
    let engine = Casifin::with_defaults();
    let rate = Rate::new(Decimal::new(5, 2), Compounding::Discrete(1))?;
    let fv = engine.fv(rate, 10, Money::ZERO, Money::from(10_000), PaymentDue::End)?;
    println!("Future value: {}", fv);
    Ok(())
}

3. Calculate a mortgage

Generate a full 30-year amortization schedule and inspect the first payment.

rustlet engine = Casifin::with_defaults();
let principal = Money::from(300_000);
let rate = Rate::new(Decimal::new(425, 4), Compounding::Discrete(12))?
    .with_convention(DayCount::Actual365);
let schedule = engine.mortgage(principal, rate, 360).build()?;

println!("Monthly payment: {}", schedule.entries[0].payment);
println!("Total interest: {}", schedule.total_interest);

4. Evaluate an investment

Compute NPV and IRR for a project with uneven cash flows.

rustlet flows = CashFlowStream::new(vec![
    CashFlow::new(Money::from(-100_000)),
    CashFlow::new(Money::from(15_000)),
    CashFlow::new(Money::from(15_000)),
    CashFlow::new(Money::from(15_000)),
    CashFlow::new(Money::from(15_000)),
    CashFlow::new(Money::from(565_000)),
]);

let npv = engine.npv(Decimal::new(10, 2), &flows)?;
let irr = engine.irr(&flows)?;

SDK usage guide

The Casifin struct is the unified facade. It carries a Config and forwards calls to the underlying crates.

Construction

rustlet engine = Casifin::with_defaults();     // eps=1e-12, max_iter=1000, guess=0.1
let custom = Casifin::new(Config::builder().eps(Decimal::new(1, 10)).build());

TVM shortcuts

rustlet pv = engine.pv(rate, nper, pmt, fv, PaymentDue::End)?;
let fv = engine.fv(rate, nper, pmt, pv, PaymentDue::End)?;
let pmt = engine.pmt(rate, nper, pv, fv, PaymentDue::End)?;
let nper = engine.nper(rate, pmt, pv, fv, PaymentDue::End)?;
let rate = engine.rate(nper, pmt, pv, fv, PaymentDue::End)?;

Cash flow analysis

rustlet npv  = engine.npv(Decimal::new(8, 2), &flows)?;
let irr  = engine.irr(&flows)?;
let xnpv = engine.xnpv(Decimal::new(8, 2), &dated_flows)?;
let xirr = engine.xirr(&dated_flows)?;

Amortization builder

rustlet schedule = engine
    .mortgage(principal, rate, 360)
    .with_payment_modifier(|_period, base| base + Money::from(200))
    .build()?;

Ratio functions

Ratio functions are glob-re-exported from casifin_ratios, so you can call them directly through the SDK: 

rustuse casifin_sdk::*;

let current = current_ratio(Money::from(500_000), Money::from(250_000))?;
let roe     = return_on_equity(Money::from(100_000), Money::from(500_000))?;
let sharpe  = sharpe_ratio(Decimal::new(12, 2), Decimal::new(3, 2), Decimal::new(15, 2))?;

Depreciation & inventory

rustlet sl = StraightLine;
let dep = sl.depreciate(Money::from(10_000), Money::from(2_000), 5, 1)?;

let fifo = Fifo;
let cogs = fifo.cogs(&lots, 150)?;
